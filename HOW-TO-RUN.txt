TraceFind — upgraded Lost & Found (5th semester project)
=======================================================

FRONTEND (React + Vite + Tailwind)
  cd frontend
  npm install
  npm run dev            ->  http://localhost:5173
  npm run build          ->  production build in dist/

  No .env needed. Defaults are baked in (see .env.example to override).

BACKEND (FastAPI)
  cd backend
  pip install -r requirements.txt
  copy .env.example to .env and fill SUPABASE_SERVICE_KEY
  uvicorn app.main:app --reload --port 8000

DATABASE (Supabase)
  Run supabase/schema.sql once in the Supabase SQL editor.
  It is idempotent and includes the NaN-safe match_items() function.

IMPORTANT — repair old listings
  Rows created while the embedding bug existed contain all-zero vectors.
  Re-save those listings from the app (or re-run the insert) so matching
  can see them. Query to find them:
    select id, title from items
    where description_embedding is null or vector_norm(description_embedding) = 0;

DEMO CHECKLIST (2 minutes before presentation)
  1. npm run dev (or open the deployed site)
  2. Sign in -> "Enter demo workspace"   (no password / no signup wall)
  3. Browse -> "Demo data" button        (injects sample listings)
  4. Open "Match Room"                   (show scored pairs + reasons)
  5. Press Ctrl+K / Cmd+K                (TraceBot assistant answers)
  6. Report -> 3 steps                   (live matches appear while typing)
